# LOKO Launcher — стартовый проект

Это исходный проект Android-лаунчера в красно-чёрной стилистике «Локомотива».
Он содержит главный экран, часы, поле поиска и сетку установленных приложений
с запуском по нажатию.

## Важно
Это **исходный проект**, не готовый APK. В этой среде APK не был собран и
не подписан. Для установки на OPPO Reno16 5G соберите его в Android Studio.

## Сборка APK
1. Установите Android Studio (актуальную стабильную версию).
2. Откройте папку `LOKO_Launcher` через **Open**.
3. Дождитесь синхронизации Gradle и установки Android SDK 35.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/`.
6. Перенесите APK на телефон и установите. Разрешите установку из этого источника.
7. Нажмите Home и выберите **LOKO Launcher** как приложение главного экрана.

## Что пока не реализовано
Это первая рабочая основа, а не финальный продукт: нет редактора сетки,
пакета фирменных иконок, динамического виджета счёта КХЛ, фоновых фотографий
игроков, резервного копирования и расширенных жестов. Для реальных фото игроков
используйте изображения, на которые у вас есть права.
